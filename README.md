# House_price_prediction
# 🏡 House Price Prediction using Linear Regression

## 📌 Project Overview

This project uses **Linear Regression**, a supervised Machine Learning algorithm, to predict house prices based on housing features. The goal is to understand how different features influence house prices and evaluate the model's prediction performance.

## 🎯 Objectives

* Understand the basics of supervised Machine Learning.
* Perform data preprocessing and handle missing values.
* Train a Linear Regression model.
* Evaluate model performance using R², Adjusted R², MAE, and RMSE.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## ⚙️ Project Workflow

1. Load and explore the dataset.
2. Analyze the data and identify missing values.
3. Handle missing values and encode categorical features.
4. Split the dataset into training and testing sets.
5. Train the Linear Regression model.
6. Predict house prices.
7. Evaluate the model using performance metrics.

## 📊 Model Performance

| Evaluation Metric |  Score |
| ----------------- | -----: |
| R² Score          | 0.6195 |
| Adjusted R² Score | 0.5708 |

**R² Score:** 61.95%

**Adjusted R² Score:** 57.08%

The model explains approximately 61.95% of the variation in house prices on the evaluated dataset. These results provide a baseline for further model improvement.
